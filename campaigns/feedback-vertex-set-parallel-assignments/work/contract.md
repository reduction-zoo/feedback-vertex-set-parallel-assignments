# Fixed encodings

Source: `{"vertices":[integer_labels...],"arcs":[[u,v],...],"k":integer}`. Vertices are explicitly listed and distinct; labels may be arbitrarily large signed integers. Arcs are distinct ordered pairs of listed vertices. Loops are allowed and are directed cycles. k may be any signed integer; a negative bound admits no witness. Positive source output: `{"delete":[labels...]}` with distinct listed labels, cardinality at most k, whose removal leaves no directed cycle. NO-SOLUTION: `{"status":"NO-SOLUTION"}`, valid exactly when no witness exists.

Target: `{"assignments":[{"write":string,"reads":[strings...]},...],"K":integer}`. Written variables are distinct; each read list encodes a set, with no duplicate names. Reads may mention the assignment's own variable or external variables not written by any assignment. K is any signed integer. Positive output: `{"order":[assignment_indices...]}` is a permutation of all indices. Its cost is the number of pairs of distinct assignments (i,j) for which i appears earlier and write(i) belongs to reads(j). A pair contributes one regardless of other reads; self-reads are not a pair of distinct assignments. Require cost <=K. Negative output has the same NO-SOLUTION encoding and requires absence of a qualifying permutation.

Both endpoints have valid outputs on every admitted input. Empty ordering/deletion sets and negative bounds are explicit cases. Numerical data are exact; JSON decimal spelling represents the same integers with polynomially equivalent size to binary.

`python algorithm.py` reads one source JSON on stdin and writes one target JSON. `python algorithm.py --extract` reads `{"source":source,"target_solution":solution}` and writes a source output. Both modes are deterministic, solver-free, polynomial and stateless across processes. Diagnostics use stderr and failures exit nonzero. The decoder premise is every valid target output, not a particular canonical ordering. Execution failure or unknown is never a semantic negative answer.
