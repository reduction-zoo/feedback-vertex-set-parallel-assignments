## Correctness

The exact problem is threshold search with a negative answer, not optimization. Every qualifying permutation must decode; optimality of the target output is neither promised nor needed.

`work/algorithm.py:14`–22 creates exactly the graph in `work/proof.md:11`–15: each split pair contributes one arc, each source arc has k+1 private middle vertices, and assignment s reads the variables at the heads of its outgoing arcs. Therefore a backwards graph arc is exactly an earlier write read by a later assignment. This is a count of distinct conflicting assignment pairs. There are no duplicate read entries or variable writes, and source loops become length-three cycles rather than ignored self-reads.

The protection lemma at `work/proof.md:19` is sound. Reversing a protected endpoint relation reverses at least one arc on each of k+1 arc-disjoint paths. Those arcs correspond to different ordered assignment pairs and cannot share a unit of cost. The lemma does not incorrectly assert that all individual protected arcs must point forward. `work/algorithm.py:31`–32 decodes only reversed split arcs; their count is bounded by the full cost. A surviving source cycle would force a strict cyclic chain of split and protected endpoint inequalities (`work/proof.md:23`), including for a loop. This proves recovery for every feasible target order, including wasted path budget.

For completeness, deleting the split arcs of a feedback vertex set leaves no cycle in H: an in-vertex on a cycle must use its split arc, and every intervening path represents a source arc. Its projection would otherwise contain a surviving source cycle. A topological order reverses only deleted split arcs (`work/proof.md:29`–31). Thus target and source witness existence agree, justifying unchanged NO-SOLUTION recovery at `work/algorithm.py:26`–27. Finite output sets and the explicit negative semantics make both problems total in the specified multivalued sense.

The branches at `work/algorithm.py:9`–12 handle negative k, k>=n, and empty vertex lists correctly. In the latter branch recovery returns all source vertices. No positive output is valid in the negative branch, so recovery need not handle a malformed positive permutation there. The contract restricts legal source encodings to distinct integer labels and distinct arcs; the implementation need not validate inputs outside this promise.

Complexity claims at `work/proof.md:35`–39 are adequate. In the only expansion branch, b=k+1<=n, giving N=2n+bm and M=n+2bm. Output length is O((n+nm)log(n+nm+2)+1); huge input labels and thresholds are read and compared at polynomial bit cost.
