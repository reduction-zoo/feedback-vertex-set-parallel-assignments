# Independent testing foundation

Initial commit 4a2afea precedes all code and tests. A preliminary conceptual mechanism was already considered; the sequencing deviation is transparently charged to round 001. No construction code or experiments have yet run. These oracles use only the fixed endpoint definitions.

Source oracle: Z3 chooses one deletion Boolean per explicitly listed vertex. Their sum is bounded by k. For each arc u->v, require either endpoint deleted or an integer rank for u smaller than the rank for v. A remaining directed cycle contradicts strict rank inequalities; every acyclic remaining graph admits topological ranks. Thus satisfiability is equivalent to a size-bounded feedback vertex set, including loops. No rank bounds or pairwise distinct ranks are needed. Validation independently checks cardinality, listed labels and acyclicity by iterative removal of indegree-zero vertices.

Target oracle: assign every assignment a distinct integer rank in 0..N-1. For every ordered pair of distinct assignments where the first writes a variable read by the second, add a Boolean penalty for the first's rank being smaller. The sum is bounded by K. This directly implements conflicting pair count, not number of saved variables or live registers. Self-reads and external reads create no pair. Distinct feasible rank models produce up to four target witnesses; lack of any model is conclusive NO-SOLUTION. A separate validator counts pairs directly in the returned permutation.

Only Z3 SAT or UNSAT is accepted; unknown or a process failure raises. No solver/subprocess timeouts. The first self-test failed because Z3 Distinct on an empty list cannot infer a context. The failed code and evidence are preserved at 2f2dd01 and evidence/prepare-failure.txt. Omitting that vacuous constraint repairs the API usage without changing semantics or expected answers.

Passing self-test: ten source cases with exhaustive deletion-set ground truth; all 64 loopless dependency patterns on three assignments at optimum-1, optimum and a 5001-digit bound (192 threshold checks), with optimum independently obtained by all six permutations. Additional cases cover empty instances, self/external reads, wrong orientation, repeated/missing indices, and a 5001-digit vertex label/source threshold. Finite checks establish no reduction theorem.
